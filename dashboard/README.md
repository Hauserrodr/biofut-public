# BIOFUT Analytics Dashboard

A modern, responsive dashboard for analyzing BIOFUT player and team statistics.

## Features

- **Dashboard Overview**: Get a quick overview of key metrics and statistics
- **Player Statistics**: Detailed analysis of individual player performance
- **Team Analysis**: Comprehensive team performance metrics
- **Performance Calculators**: Calculate player synergies and head-to-head matchups
- **Rankings**: View player rankings based on various metrics
- **Settings**: Configure dashboard settings and data sources

## Technologies Used

- React
- React Router
- Recharts for data visualization
- Tailwind CSS for styling
- XLSX for Excel file processing

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository
```bash
git clone https://github.com/yourusername/biofut-dashboard.git
cd biofut-dashboard
```

2. Install dependencies
```bash
npm install
# or
yarn install
```

3. Start the development server
```bash
npm run dev
# or
yarn dev
```

4. Open your browser and navigate to `http://localhost:5173`

## Data Sources

The dashboard can work with different data sources:

- Excel files (XLSX)
- API connections
- Database connections

By default, the dashboard uses mock data for demonstration purposes. To use your own data, upload an Excel file through the Settings page or configure an API/database connection.
