# Como contribuir

1. Peça para entrar no time **BioFut Devs** (fale com o Gab no grupo, mande seu usuário do GitHub).
2. Escolha uma issue aberta, comente "pego essa" para ninguém duplicar.
3. Crie uma branch `issue-<número>-<resumo>`, faça o PR para `main` e cite a issue (`Fecha #12`).
4. Um outro dev revisa. Merge feito = issue fechada = bounty pago (se tiver).

Regras:

- Nada de dados reais do grupo em commits: planilha, telefones, prints, export do WhatsApp. Use dados de exemplo.
- Nada de chaves de API ou senhas no código. Use `.env` (já está no `.gitignore`).
- O bot de WhatsApp nunca manda mensagem sem um comando explícito de alguém do grupo.
