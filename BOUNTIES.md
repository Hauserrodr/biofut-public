# BioDevs: bounties pagos em gols e assistências

Cada issue com etiqueta `bounty` paga **gols (G)** e **assistências (A)** de BioFut, a mesma moeda do BioBet. Não é dinheiro: é saldo para apostar no BioBet e vale pontos no ranking dos BioDevs.

## Tabela de pagamento

| Etiqueta | Tamanho | Paga |
|---|---|---|
| `bounty:P` | ajuste pequeno, doc, bug simples | 1A |
| `bounty:M` | uma feature pequena (uma tela, um comando do bot) | 1G |
| `bounty:G` | feature grande (pipeline, draft, BioBet) | 2G + 2A |

O Gab (ou quem ele designar) pode subir o valor de uma issue difícil antes de alguém pegar.

## Regras

- Paga quando o PR é **mergeado** e a issue fecha. PR abandonado não paga.
- Um bounty por issue. Dividiu o trabalho em dupla? Divide o pagamento (G vira 2A se precisar).
- O saldo vai para o seu jogador no BioBet. Até o BioBet existir, ele fica no livro-caixa abaixo.
- Gols e assistências de bounty contam separados das estatísticas de campo: a artilharia da pelada continua sendo só de jogo.
